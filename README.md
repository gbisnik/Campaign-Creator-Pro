Smart Campaign Builder that allows teams to generate hundreds or thousands of compliant campaign rows at once.
The Builder has an editable excel like view where data can be put into standard set of columns. The standard set of master columns will come from column A “Field Name” from your excel sheet. The user should be able to work on a master view and should be able to take snapshot of it which can be saved in local as excel. At any point of time, user should be able to upload any of the last snapshots in the master view to continue working on that snapshot. 
The Builder has a file upload box where user can upload excel files which will have subset of columns from master columns.
The Builder Should have pre-activation validation on the basis of 
A) “Data Type” column which indicates type of field
B)  “Required” column which indicates whether the column should be there or not.
